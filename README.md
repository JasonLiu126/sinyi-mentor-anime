# 信義新星｜正式版公開展示

GitHub Pages 展示版包含首次適性測驗、商圈地圖、九欄社區勘查、分次儲存草稿、店長審核示範、角色收藏及公開小學堂。

知識小學堂的稅務第 1～3 關使用公開練習題。三關皆嵌入國稅局的 YouTube 公開影片，無法載入時使用自製補課短片。作答、補課進度、草稿及審核示範皆儲存在各訪客自己的瀏覽器。

## GitHub Pages

在 Settings → Pages 選 Deploy from a branch，分支 main、資料夾 /(root)。

## V4「遊戲大廳風」改版

外觀改成手機遊戲大廳：預設首頁是主城，底部導覽 5 格（冒險地圖、角色、主城、夥伴、試煉）。資料、計分、審核與存檔邏輯沿用原本程式，V4 只包裝既有函式、重排畫面與換外觀。

| 檔案 | 內容 |
|---|---|
| `theme-v4.css` | 色票、字體、共用元件與各頁 V4 外觀（最後載入） |
| `v4-adapters.js` | 只讀既有資料，換算職業、等級、主線、夥伴等顯示數值 |
| `lobby-v4.js` | HUD、導覽、主城、夥伴編隊 |
| `journal-v4.js` | 冒險日誌、懸賞板、委託詳情 |
| `map-v4.js` | 冒險地圖、探索副本（情報拼圖） |
| `handbook-v4.js` | 角色頁（雷達、裝備欄、天賦樹） |
| `showcase-v4.js` | 召喚祭壇、夥伴名冊、參觀同事主城 |
| `academy-v4.js` | 試煉之塔、實戰對練 VS／戰鬥／結算 |

### 任務檢核模擬（日報表／公會長審核）

`task-verify-v4.js` 把任務分成兩類，分類寫在檔案開頭的 `V4_TASK_VERIFY`：

- 📊 日報表自動核對：新人按「核對日報表並完成」，今日日報達標就直接完成；未達標會變成「等待日報」，店長在公會長後台登錄日報後自動核對。
- 👑 公會長審核：新人「交給公會長審核」後變成「審核中」，店長在公會長後台（manager.html）的「任務審核」核可或退回（退回需填原因，新人可修改後重送）。

尚未接資料庫：日報與審核清單存在瀏覽器 `sinyi-v4-task-verify-v1`，新人與店長需用同一台瀏覽器。之後接資料庫只要替換 `v4VerifyLoad`／`v4VerifySave`。

## 公會長後台（manager.html）

給店長用的 Web 管理工具，和新人 APP 分開：`manager.html`（舊網址 `?view=manager` 會自動導過去）。

| 功能 | 內容 |
|---|---|
| 總覽 | 待審任務、待審勘查、今日日報、新人等級與各路線進度 |
| 任務審核 | 👑 任務送審與指派任務回報，核可或退回（退回需原因） |
| 社區勘查審核 | 9 欄勘查內容，核可（鑑定通過）或退回補正 |
| 新人能力 | 職業、等級、專業／開發／銷售分數、雷達圖、各路線任務完成狀況 |
| 日報表 | 依日期登錄五項日報數字、查看近期日報 |
| 指派任務 | 發布懸賞任務、篩選與取消 |

核可與日報只改狀態；獎勵由新人 APP 讀到後自動發放（同一瀏覽器的另一個分頁也會即時同步）。尚未接資料庫，後台讀寫的是同一台瀏覽器的新人存檔；之後接資料庫時替換 `manager.js` 的 `mLoad`／`mSave` 與新人端的 `v4VerifyLoad`／`v4VerifySave`。
