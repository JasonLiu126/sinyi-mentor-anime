# 信義新星｜正式版公開展示

GitHub Pages 展示版包含首次適性測驗、商圈地圖、九欄社區勘查、分次儲存草稿、店長審核示範、角色收藏及公開小學堂。

知識小學堂的稅務第 1～3 關使用公開練習題。三關皆嵌入國稅局的 YouTube 公開影片，無法載入時使用自製補課短片。作答、補課進度、草稿及審核示範皆儲存在各訪客自己的瀏覽器。

## GitHub Pages

在 Settings → Pages 選 Deploy from a branch，分支 main、資料夾 /(root)。

### 任務檢核模擬（日報表／公會長審核）

`task-verify-v4.js` 把任務分成兩類，分類、難度與成長能力寫在檔案開頭的 `V4_TASK_VERIFY`：

- 📊 日報判定：新人每天在任務頁「今日日報」填數字送出 → 店長在後台「日報審核」核可（可先修正數字）或退回。只有核可的日報會計入，從新人接任務當天起累計，達門檻自動完成。
- 👑 店長判定：新人送審（擋手機、身分證、Email 等個資）→ 店長在「任務審核」核可或退回；退回 3 次任務結束。
- 經驗由難度決定（小 20／中 40／大 80），依權重分到 1～3 項能力；角色總等級是所有能力加總。
- 送審超過 2 天未審，後台總覽與卡片會標示逾時（正式版改為通知）。
- 覺醒試煉只做一次，作答紀錄（系統推薦、新人選擇）存在 `sinyi-v4-quiz-history-v1`；店長可在後台「開放重測」。

尚未接資料庫：資料存在瀏覽器 localStorage（`sinyi-v4-task-verify-v1`、`sinyi-v4-task-log-v1`、`sinyi-v4-manager-log-v1` 等），新人與店長需用同一台瀏覽器。

## 公會長後台（manager.html）

給店長用的 Web 管理工具，和新人 APP 分開：`manager.html`（舊網址 `?view=manager` 會自動導過去）。

| 功能 | 內容 |
|---|---|
| 總覽 | 待審任務／日報／勘查數、逾時提醒、新人等級與各路線進度 |
| 任務審核 | 👑 任務送審與指派任務回報，核可或退回（需原因，最多 3 次） |
| 社區勘查審核 | 9 欄勘查內容，核可（鑑定通過）或退回補正 |
| 新人能力與紀錄 | 能力分數與雷達圖、覺醒試煉紀錄與開放重測、任務紀錄 |
| 日報審核 | 待審日報（可修正數字後核可）、退回、近期紀錄 |
| 指派任務 | 判定方式、難度、1～3 項成長能力與權重、期限；每人每天最多 3 件／120 EXP、進行中最多 5 件；不發金幣 |
| ↺ 重置 Demo | 清除這台瀏覽器所有 `sinyi-*` 資料，已開著的新人 APP 會自動重新載入，從覺醒試煉開始 |

核可只改狀態；獎勵由新人 APP 讀到後自動發放（同一瀏覽器的另一個分頁也會即時同步）。之後接資料庫時替換 `manager.js` 的 `mLoad`／`mSave` 與新人端的 `v4VerifyLoad`／`v4VerifySave`。
