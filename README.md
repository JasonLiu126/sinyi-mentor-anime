# 信義新星｜正式版公開展示

GitHub Pages 展示版包含首次適性測驗、商圈地圖、九欄社區勘查、分次儲存草稿、店長審核示範、角色收藏及公開小學堂。

知識小學堂的稅務第 1～3 關使用公開練習題。三關皆嵌入國稅局的 YouTube 公開影片，無法載入時使用自製補課短片。作答、補課進度、草稿及審核示範皆儲存在各訪客自己的瀏覽器。

## GitHub Pages

在 Settings → Pages 選 Deploy from a branch，分支 main、資料夾 /(root)。

## V4「遊戲大廳風」改版

外觀改成手機遊戲大廳：預設首頁是主城，底部導覽 5 格（冒險地圖、角色、主城、夥伴、試煉）。資料、計分、審核與存檔邏輯沿用原本程式，V4 只包裝既有函式、重排畫面與換外觀。

| 檔案 | 內容 |
|---|---|
| `theme-v4.css` | 色票、字體、共用元件與各頁 V4 外觀（最後載入） |
| `v4-adapters.js` | 只讀既有資料，換算職業、等級、主線、夥伴等顯示數值 |
| `lobby-v4.js` | HUD、導覽、主城、夥伴編隊 |
| `journal-v4.js` | 冒險日誌、懸賞板、委託詳情 |
| `map-v4.js` | 冒險地圖、探索副本（情報拼圖） |
| `handbook-v4.js` | 角色頁（雷達、裝備欄、天賦樹） |
| `showcase-v4.js` | 召喚祭壇、夥伴名冊、參觀同事主城 |
| `academy-v4.js` | 試煉之塔、實戰對練 VS／戰鬥／結算 |
| `global-v4.js` | 職業覺醒、全域 Modal、學長浮動頭像 |
| `anim-v5.js`／`anim-v5.css` | V5 六段動畫（召喚、融合、升星、任務完成、升級、職業覺醒） |
| `assets/v4/` | 職業角色、IP 去背圖、學長圖（檔名固定，可直接換高解析版） |

新增的存檔只有夥伴編隊 `sinyi-v4-party-v1`（`{version:1, ids:[隊長, 第 2 位, 第 3 位]}`），舊存檔沒有時自動取擁有中星等最高的 3 位。既有 localStorage key 與格式不變。
